Find K Closest Elements

Binary search on the left boundary of a sliding window
◆ Visual Explanation

Given a sorted array arr, and two integers k and x, return the k closest integers to x, sorted in ascending order.

If two integers have the same distance to x, the smaller one is considered closer.

Input: arr = [1,2,3,4,5], k = 4, x = 3
Output: [1,2,3,4]
Medium Time: O(log(n−k) + k) Space: O(1)

💡 Key Insight

The answer is always a contiguous window of size k in the sorted array. Instead of finding the closest element and expanding, we can binary search for the window's left boundary.

At each step, compare x − arr[mid] vs arr[mid + k] − x to decide which direction to slide the window.

Binary Search Approach

  1. Set lo = 0, hi = n − k
  2. While lo < hi:
      • mid = (lo + hi) / 2
      • If x − arr[mid] > arr[mid+k] − x, then lo = mid + 1
      • Otherwise, hi = mid
  3. Return arr[lo..lo+k]
