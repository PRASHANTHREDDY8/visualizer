Sliding Window Maximum

Find the maximum in every contiguous subarray of size k using a monotonic deque

Visual Explanation

Problem Statement

Given an array of integers nums and a sliding window of size k, return an array of the maximum value in each window as it slides from left to right across the array.

Input
nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
Output
[3, 3, 5, 5, 6, 7]
Time: O(n) Space: O(k) Hard

Key Insight

Maintain a monotonic decreasing deque of indices. The front always holds the index of the current window's maximum. When a new element arrives, pop all smaller elements from the back — they can never be the maximum while the new element exists in the window. This ensures O(1) access to the max and O(n) total time since each element is pushed and popped at most once.

Approach: Three Operations Per Element

1

Clean the Back

Pop elements from the back of the deque while they're smaller than the incoming element. They can never be the window max.

2

Evict the Front

If the front index has fallen outside the current window (index == i - k), remove it. It's no longer a candidate.

3

Record the Max

Once the window has k elements (i ≥ k-1), the front of the deque holds the index of the current maximum.

The Monotonic Deque

The deque stores indices, and the values at those indices are always in decreasing order from front to back. This invariant guarantees the front is always the maximum.
