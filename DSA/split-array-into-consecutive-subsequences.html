LeetCode 659

Split Array into Consecutive Subsequences

Greedy approach with frequency + tails hash maps

◈ Visual Explanation

Problem Statement

Given a sorted integer array nums, determine if it can be split into subsequences where each subsequence consists of consecutive integers and has length ≥ 3.

Example
Input: nums = [1, 2, 3, 3, 4, 5]
Output: true
Split into [1,2,3] and [3,4,5] — both consecutive, both length ≥ 3
Example 2
Input: nums = [1, 2, 3, 3, 4, 4, 5, 5]
Output: true
Split into [1,2,3,4,5] and [3,4,5]
Example 3
Input: nums = [1, 2, 3, 4, 4, 5]
Output: false
Cannot form valid split — the second 4 cannot start or extend a valid subsequence
⚡ Key Insight

For each number, prefer appending it to an existing subsequence over starting a new one. Why? Starting a new subsequence "locks in" a commitment for the next two numbers — if they aren't available, we fail. Extending an existing sequence is always safe.

Greedy Approach — Two Maps

We maintain two hash maps:

freq[num]
Remaining count of each number still available to use
tails[num]
Number of valid subsequences that end with num and want num+1 next

For each number in the sorted array:

  1. If freq[num] == 0 → skip (already used)
  2. If tails[num-1] > 0 → append to existing subsequence
  3. Else if freq[num+1] > 0 AND freq[num+2] > 0 → start new length-3 subsequence
  4. Else → return false
Time: O(n) Space: O(n)
