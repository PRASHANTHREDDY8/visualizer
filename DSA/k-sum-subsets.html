K-Sum Subsets

Find all subsets of distinct positive integers whose elements sum to a target value k using backtracking.

◈
Problem & Approach

Given an array of n distinct positive integers, find all possible subsets that sum to a target k. Return a 2D array of all valid subsets.

INPUT ARRAY
target k = 9 →
VALID SUBSETS
[2, 3, 4] [1, 4, 4] [1, 3, 5] [4, 5]
💡 Key Insight Use backtracking to explore all possible include/exclude decisions for each element. At each index, either include the current number in the subset or skip it. Prune branches early when the running sum exceeds k.
Step 1
Sort the array (enables early pruning when sum exceeds target)
Step 2
Recurse: at each index, choose to include or skip the element
Step 3
If sum == k, record the current subset as a valid solution
Step 4
If sum > k or index out of bounds, backtrack (prune)
Time: O(2^n) Space: O(n) recursion depth
