Morris Inorder Traversal

Inorder traversal of a binary tree in O(1) space using threaded links

Time: O(n) Space: O(1)
Section 1

Visual Explanation

Problem Statement

Given the root of a binary tree, return its inorder traversal (left → root → right) using O(1) extra space — no recursion stack, no explicit stack, no parent pointers.

Input Tree
→
Output
[1, 2, 3, 4, 6, 7]

💡 Key Insight

Instead of a stack, use temporary threads: link each node's inorder predecessor's right pointer back to the node. This creates a "breadcrumb trail" that lets you return to a parent without consuming memory. Every thread you create is later removed, leaving the tree unmodified.

Algorithm (Morris Traversal)

  1. Set curr = root
  2. If curr.left is null → visit curr, move right
  3. Else find inorder predecessor pred in left subtree
  4. If pred.right is null → create thread (pred.right = curr), move left
  5. If pred.right == curr → remove thread, visit curr, move right
  6. Repeat until curr is null
Approach Time Space Trade-off
Recursive O(n) O(h) Simplest code, but O(n) stack space for skewed trees
Iterative (stack) O(n) O(h) Explicit stack; avoids recursion limit but same space
Morris Traversal ✓ O(n) O(1) Constant space by temporarily mutating the tree
