LeetCode #1

Two Sum

Given an array of integers and a target, find two numbers that add up to the target. Return their indices.

Section 1

Visual Explanation

Problem Statement

Given an array of integers nums and an integer target, return the indices of the two numbers such that they add up to the target.

You may assume that each input has exactly one solution, and you may not use the same element twice.

Example
nums = [2, 7, 11, 15]
target = 9

Output
[0, 1]
Because nums[0] + nums[1] = 2 + 7 = 9

⚡ Key Insight

Instead of checking every pair (O(n2)), use a hash map to remember numbers you have already seen. For each number, compute its complement (target - current) and check if that complement is already in the map. This gives a one-pass O(n) solution.

Brute Force Slow

Check every pair of elements with two nested loops. If their sum equals the target, return those indices.

Time O(n2)
Space O(1)

Hash Map Optimal

Iterate once. For each element, check if its complement exists in a hash map. If not, store the element and its index.

Time O(n)
Space O(n)

Algorithm

function twoSum(nums, target) { const map = new Map(); for (let i = 0; i < nums.length; i++) { const complement = target - nums[i]; if (map.has(complement)) { return [map.get(complement), i]; } map.set(nums[i], i); } }
