Comparisons with Alternatives

Routing Algorithm Approaches

ApproachKey IdeaProsConsUsed By
Contraction Hierarchies + A*CHOSEN Pre-compute shortcut edges between important nodes; A* guides the search Sub-second continental routes; memory efficient Expensive pre-processing; static weights hard to update Google Maps, OSRM
Dijkstra's (plain) Explore all nodes by increasing distance from source Optimal; simple to implement Too slow for large graphs (millions of nodes) Educational, small networks
A* with Landmarks (ALT) Pre-selected landmarks provide lower bounds for A* heuristic Good speedup; handles dynamic weights Moderate preprocessing; less effective than CH at continental scale Research, some commercial routers
Graph Partitioning (PUNCH) Partition road graph; precompute distances between boundary nodes Excellent for hierarchical networks Complex implementation; partition quality matters Apple Maps (variant)

Map Tile Serving Approaches

ApproachKey IdeaProsConsUsed By
Vector Tiles + Client RenderingCHOSEN Send compressed geometry data; client renders with GPU 10x smaller payload; dynamic styling; smooth rotation/tilt Client must have GPU; more complex client code Google Maps, Mapbox GL
Pre-rendered Raster Tiles Server renders PNG/JPEG at each zoom level Simple client; works everywhere Massive storage (petabytes); no dynamic styling; blurry on rotation OpenStreetMap (default), legacy systems
On-demand Raster Rendering Render tiles server-side when requested, cache results Flexible styling; lower storage than pre-rendered Cold start latency; high server CPU cost Tile servers with caching layers

Real-time Traffic Architecture

ApproachKey IdeaProsConsUsed By
GPS Probe + Map Matching + Segment SpeedsCHOSEN Aggregate GPS from phones; map-match to road segments; compute segment speeds Massive coverage; real-time; no hardware cost Privacy concerns; GPS noise; needs large user base Google Maps, Waze
Road Sensors (Inductive Loops) Physical sensors in road surface count vehicles Accurate count; no privacy issue Expensive to deploy/maintain; limited coverage Highway authorities
Camera-based (ANPR/CV) Cameras track license plates or vehicle flow Visual verification; incident detection Weather-sensitive; expensive; privacy issues Smart cities, toll roads

Use Cases & Common Pitfalls

Primary Use Cases

Turn-by-Turn Navigation

Real-time routing with traffic awareness, rerouting on congestion, voice guidance, and lane-level instructions.

1B+ daily routes

Place Discovery & Search

Searching for nearby restaurants, businesses, and POIs with reviews, hours, and photos. Geocoding addresses.

5B+ daily searches

Ride-hailing / Delivery Dispatch

ETA prediction for driver matching, multi-stop route optimization, real-time driver tracking for customers.

100M+ daily rides globally

Fleet & Logistics Management

Vehicle tracking, route optimization for delivery fleets, geofencing, and distance-matrix computations for TSP solvers.

10M+ fleet vehicles

Anti-use Cases

Indoor Navigation

GPS doesn't work indoors. Requires BLE beacons, Wi-Fi fingerprinting, or UWB. A fundamentally different positioning system.

Centimeter-precision Surveying

Consumer GPS has ~3m accuracy. Surveying needs RTK-GPS, total stations, and LiDAR — different hardware stack.

Offline-first with No Pre-download

Vector tiles still need initial download. Truly disconnected scenarios need pre-built map packages (like OsmAnd).
