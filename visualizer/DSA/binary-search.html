Efficient search on sorted arrays — halve the search space at every step

Problem Statement

Given a sorted array of integers and a target value, return the index of the target if it exists, or -1 if it does not.

Input:
1
3
5
7
9
11
13
target = 7 ➔ Output: index 3
Time: O(log n) Space: O(1)
Key Insight

Because the array is sorted, comparing the target with the middle element tells you which half to discard entirely. Each comparison eliminates 50% of the remaining elements, giving logarithmic time complexity. For an array of 1,000,000 elements, binary search needs at most 20 comparisons instead of 1,000,000.

Approach Overview

Maintain two pointers, low and high, that bound the current search region. Repeatedly compute the mid index and compare.

Step 1

Initialize Pointers

Set low = 0 and high = n - 1 to cover the entire array.

Step 2

Compute Mid

Calculate mid = Math.floor((low + high) / 2) to find the center of the current range.

Step 3

Compare & Decide

If arr[mid] === target, return mid. If arr[mid] < target, move low up. If arr[mid] > target, move high down.

Step 4

Repeat or Finish

Continue while low ≤ high. If the loop ends without finding, return -1.
