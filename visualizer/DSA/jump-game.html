Key Insight

You don't need to find an actual path. Just track the farthest reachable index as you scan left to right. If at any position i, you find i > maxReach, it means there's a gap you can't cross. Otherwise, update maxReach = max(maxReach, i + nums[i]).

4

If the loop completes, the last index is reachable — return true

function canJump(nums) {
  let maxReach = 0;
  for (let i = 0; i < nums.length; i++) {
    if (i > maxReach) return false;
    maxReach = Math.max(maxReach, i + nums[i]);
  }
  return true;
}
